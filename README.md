 Java Banking Program

A simple console-based banking application built with Java. This project allows users to manage a bank balance by making deposits, withdrawing money, and checking their current balance.

I created this project to practice Java fundamentals, including methods, loops, conditional statements, and user input.

Features

Check Balance – View your current account balance.

Deposit Money – Add money to your account.

Withdraw Money – Withdraw money if sufficient funds are available.

Input Validation – Prevent negative deposits, negative withdrawals, and withdrawals exceeding the available balance.

Interactive Menu – Perform multiple banking operations until you choose to exit.

 
How to Run

Clone the repository:

git clone https://github.com/Orfeo03/BankingProgramJava.git

Open the project in IntelliJ IDEA.

Navigate to src/Main.java.

Run the Main class.

 Compile and run using the terminal:

javac src/Main.java
java -cp src Main
